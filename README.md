# 月满 · 礼至

适用于工作人员使用同一台平板或电脑的中秋现场抽奖。纯 HTML、CSS、JavaScript，无需安装依赖或构建，可放在 GitHub Pages 的静态站点目录中。全部资源使用相对路径，支持仓库子路径。

## 开始使用

打开 index.html，输入活动署名、确认概率、设置至少 6 位的管理员口令，填写甲方已确认的使用条件，点击“锁定配置，开启礼遇”。如浏览器限制本地文件功能，请通过 HTTPS 网站或本机 HTTP 服务访问。

默认中奖概率：无门槛 200 元券 25%、无门槛 100 元券 50%、满 5000 可用 500 元券 10%、满 3000 可用 300 元券 10%、舒敏之星 5%。可输入两位小数，合计必须为 100%。这是独立随机概率，不是固定库存。其他未实际参与抽奖的奖品未放入转盘。

活动页点击转盘中央抽奖。结果预先保存，动画期间刷新会恢复同一次中奖结果，不重新抽取。工作人员完成核对后点击“已记录，迎接下一位”。本地记录只证明本站生成过该次结果，不是核销系统。

## 管理与退出

长按左上角“月满 · 礼至”3 秒，或按 Ctrl + Shift + L，输入口令即可返回设置。修改设置时，两个口令栏均留空可保留现有口令。设置页可以导出本机抽奖记录。浏览器刷新或重启后沿用该浏览器保存的活动状态。

右上角按钮用于浏览器支持的全屏模式。网页不能阻止用户关闭标签页、离开浏览器或使用系统退出手势。

## 现场使用边界

- 使用同一个浏览器、同一网站地址，建议只开一个活动标签页。本版本未提供跨标签同时抽奖的事务锁。
- 配置、记录和活动锁定保存在本机 localStorage；更换浏览器、清除网站数据、无痕模式关闭后，都可能丢失。建议活动后导出记录。
- 管理口令使用加盐 SHA-256 摘要保存。它用于防止现场误操作，不是服务端身份认证；能够操作浏览器开发工具的人仍能查看概率、改动本机状态。
- 忘记口令没有远程找回机制。清除该网站本地数据可重新设置，但也会删除本地抽奖记录。
- 没有一人一次资格校验、库存管理或防重复兑奖。由现场工作人员组织参与和核对领取。
- 有效期、适用范围、核销方式等请填写甲方真实确认的说明；程序未编造这些条款。

## GitHub 托管

将 index.html、style.css、app.js、festival.jpg、favicon.svg 和 .nojekyll 一起放到目标 GitHub Pages 发布目录。无需构建命令。未自动上传或发布到 GitHub，因为本任务未指定目标仓库。

## 已完成验证

概率合计校验；配置锁定；刷新保留活动页；动画中刷新恢复原中奖结果且只记录一次；错误口令拒绝、正确口令解锁；100% 舒敏之星配置正确命中；电脑、平板、手机宽度检查；浏览器无 JavaScript 运行错误。
